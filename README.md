# AACHIP-I2C-SNIFFER
AACHIP I2C Sniffer 是 I²C 通訊觀察與分析工具，協助開發人員檢視時脈與資料訊號，追蹤主控端與周邊裝置的通訊流程，並排查匯流排問題。

支援的擷取硬體、最高通訊速率、解碼功能及檔案格式，請參考各版本發布說明。

## 分析訊號

| 訊號 | 用途 |
| --- | --- |
| SCL | I²C 通訊時脈 |
| SDA | 雙向資料傳輸 |

觀察重點包含 START、Repeated START、STOP、裝置位址、讀寫方向、資料及 ACK／NACK。實際自動解碼與顯示能力以發布版本為準。

## 應用情境

- 觀察微控制器與感測器、EEPROM、RTC 等裝置的通訊。
- 排查位址錯誤、未回應、時序及資料傳輸問題。
- 協助驗證 I²C 驅動程式與硬體設計。
- 學習 I²C 通訊原理。

## 基本使用流程

1. 安裝軟體及擷取硬體所需的驅動程式。
2. 確認擷取硬體與目標匯流排的訊號電壓相容。
3. 將輸入通道連接至 SCL、SDA，並共地。
4. 依版本提供的功能，設定通道對應、取樣率及觸發條件。
5. 啟動擷取，再執行要觀察的 I²C 通訊。
6. 檢視波形及版本支援的解碼結果。

## 使用注意事項

- 觀察既有通訊時，擷取端應使用輸入模式，避免驅動或干擾匯流排。
- I²C 通常使用開汲極／開集極訊號與上拉電阻，請確認上拉電壓及阻值適合目標電路。
- 接線應盡量短，避免額外電容影響訊號上升時間。
- 取樣率需配合通訊速率並保留足夠餘裕。
- 核對裝置位址時，請區分 7 位元位址與包含讀寫位元的 8 位元表示方式。
- 10 位元位址、時脈延展及多主控等功能的分析支援，以各版本說明為準。
- 一般 I²C 解碼與特定裝置的暫存器／命令解讀不同，請搭配目標裝置資料手冊分析。
